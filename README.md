# Peter46jan Dopamine

## How do I install these formulae?

`brew install peter46jan/dopamine/<formula>`

Or `brew tap peter46jan/dopamine` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "peter46jan/dopamine"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
